# Portfolio

Source for my personal portfolio site.

**Live site:** https://portfolio-puce-nine-11.vercel.app/

## Sections

Home, About, Projects, Skills, Experience, Education and Contact.

## Tech stack

Plain HTML, CSS and JavaScript, with no framework or build step. Deployed on Vercel.

## Run locally

```bash
git clone https://github.com/Ankur377823/portfolio.git
cd portfolio
```

Then open `index.html` in a browser.

## Project structure

| Path | Purpose |
|---|---|
| `index.html` | Page content |
| `style.css` | Styles |
| `script.js` | Navigation and other interactions |
| `assets/` | Images and documents |
